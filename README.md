## 📥 How to Download & Install

### ✅ For Users (Install APK)
1. **Click the download button above** to download the `.apk` file.
2. **Open the downloaded APK** on your Android phone.
3. If prompted, **allow installation from unknown sources**.
4. Tap **Install**.
5. Launch the app and start enjoying daily motivation!

### 🧑‍💻 For Developers (Run the Project)
To run this project locally on your machine:

```bash
git clone https://github.com/aayush61203/MotivationQuotesApp-Kotlin.git
cd MotivationQuotesApp-Kotlin
```

1. Open the project in **Android Studio**
2. Let **Gradle** finish syncing
3. Connect your Android device or use an emulator
4. Press **Run ▶️** to launch the app
